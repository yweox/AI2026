Key Features

서비스 주요 핵심 기능

원하는 축제 정보를 가장 빠르고 직관적으로 찾아볼 수 있도록 설계된 차별화된 기능들입니다.

16개 구·군 현황 그리드

부산광역시 전체 및 16개 행정구역(해운대구, 중구, 부산진구 등)별 축제 개최 건수를 한눈에 확인하고 빠르게 필터링할 수 있습니다.

다차원 상세 검색 & 필터

축제명, 장소, 내용 키워드 검색은 물론 특정 날짜 지정, 개최 월 선택(1월~12월), 진행 상태(예정, 진행중, 종료) 조건 검색을 지원합니다.

4가지 뷰 모드 전환

사용자 선호에 맞춰 시각적 카드 뷰, 가독성 높은 목록 뷰, 일정 파악에 유용한 달력 뷰, 위치 기반 지도 뷰 등 다양한 화면 방식을 제공합니다.

공공데이터 실시간 수집

부산광역시 공식 공공데이터 포털 API와 직접 연동되어 지자체에서 등록한 최신 축제 일정과 정보를 가장 빠르게 업데이트합니다.

관심 축제 즐겨찾기

방문하고 싶은 축제 카드의 북마크 버튼을 클릭하여 나만의 축제 보관함에 저장이 가능하며, 상단 바에서 수량을 즉시 확인할 수 있습니다.

축제 진행 상태 배지 분류

'개최 예정', '진행중', '종료' 상태 배지와 구·군 지역 태그를 직관적으로 표기하여 현재 참여 가능한 축제를 유저가 즉시 식별합니다.

System Architecture

공공데이터 연동 & 데이터 처리 흐름

공공데이터 포털 Open API로부터 수집된 축제 데이터의 가공 과정입니다.

1

공공 API 동기화

공공데이터 포털 (data.go.kr) 부산 축제 API 실시간 호출

2

지역/날짜 파싱

16개 구·군 카테고리화 및 개최 일정 기준 상태(예정/진행/종료) 자동 계산

3

클라이언트 인메모리 필터ing

다중 조건 검색(키워드+구군+월별+진행상태) 즉시 반응 처리

4

반응형 4-View 렌더링

카드, 목록, 달력, 지도 UI 뷰 포맷으로 실시간 렌더링

부산 관광객

여행 일정과 방문 지역에 맞춰 개최 중이거나 개최 예정인 축제를 쉽게 탐색하고 이동 동선을 계획할 수 있습니다.

부산 시민

내 동네(구·군)의 이번 주말 문화 행사나 지역 축제 소식을 쉽고 빠르게 확인하고 즐길 수 있습니다.

행정 & 마케터

부산 내 16개 구·군별 축제 데이터 분포 현황을 시각적으로 파악하고 통합 정보 관리 효율을 증대시킵니다.
